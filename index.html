Đồng Bộ Google Sheets (Database Trung Tâm)

Sử dụng Google Sheets làm database dùng chung hoàn toàn miễn phí cho cả đội ngũ
Nhập URL của Web App bạn đã Deploy từ Google Apps Script trong Bảng tính của bạn.

Cách cài đặt cơ sở dữ liệu Google Sheet:

  1. Tạo 1 Google Sheet trống trong tài khoản của bạn.
  2. Vào Mở rộng (Extensions) → Apps Script.
  3. Xóa hết code cũ, dán đoạn mã bên dưới vào và nhấn Lưu:
function doGet(e) {
  var sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet();
  var val = sheet.getRange("A1").getValue();
  return ContentService.createTextOutput(val || "{}")
    .setMimeType(ContentService.MimeType.JSON);
}

function doPost(e) {
  var sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet();
  var json = e.postData.contents;
  sheet.getRange("A1").setValue(json);
  return ContentService.createTextOutput(JSON.stringify({ status: "success" }))
    .setMimeType(ContentService.MimeType.JSON);
}
  1. Nhấn Triển khai (Deploy) → Triển khai mới (New deployment).
  2. Chọn loại là Ứng dụng web (Web app).
  3. Cấu hình: Người có quyền truy cập chọn là Bất kỳ ai (Anyone).
  4. Bấm Triển khai, cấp quyền truy cập của Google Sheet và sao chép URL ứng dụng web dán vào ô bên trên.

Tài Liệu Hướng Dẫn Tính Giá

Các công thức toán học sử dụng trong hệ thống
1. Giá thành sản phẩm In:

$$\text{Base Cost} = \sum \text{Vật tư} + (\text{Giờ In} \times \text{Lương/Giờ}) + (\text{Công suất} \times \text{Giờ In} \times \text{Giá điện}) + \text{Phân bổ}$$

2. Giá thành sản phẩm Thêu:

$$\text{Base Cost} = \sum \text{Vật tư} + (\frac{\text{Mũi Thêu}}{1000} \times \text{Lương/1k Mũi}) + (\text{Công suất} \times \text{Giờ chạy} \times \text{Giá điện}) + \text{Phân bổ}$$

3. Số lượng hàng cần mua tháng tới:

$$\text{Cần Mua} = \text{Dự Báo Bán} + \text{Tồn An Toàn} - \text{Tồn Hiện Tại}$$

Lưu ý: Nếu kết quả tính ra âm (tồn kho nhiều hơn nhu cầu), số lượng cần mua sẽ được tự động quy về 0.
